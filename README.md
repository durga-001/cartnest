# CartNest: AI-Based Full-Stack E-Commerce Platform

Built with **React.js, Node.js, MongoDB, Express.js, JWT, Razorpay, Gemini API**

## 🚀 Live Demo
Check out the deployed project here:  
 [cartnest.com](https://cartnest-zj0x.onrender.com/)


## ✨ Features
- Architected a secure **Role-Based Access Control (RBAC)** system with JWT authentication and middleware-based route protection, separating Admin and User permission levels across all API endpoints.
- Integrated the **Gemini API** to power AI-driven product recommendations and auto-generated product descriptions, improving product discoverability for artisan sellers.
- Designed a normalized **MongoDB schema** and built a full order-management pipeline (cart persistence, checkout, order history) with real-time inventory checks to prevent overselling under concurrent requests.
- Built RESTful **Admin APIs** for product and order management.
